# 🎡 지역축제 데이터 분석 및 방문객 예측 시스템

전국 문화축제 데이터를 기반으로 **축제 검색, 기간별 방문객 추이 분석, 대중교통 인프라 분석, 축제 비교 및 방문객 수 예측**을 제공하는 Streamlit 기반 데이터 분석 프로젝트입니다.

---

## 📌 프로젝트 소개

지역축제와 관련된 다양한 데이터를 활용하여 축제 정보를 쉽게 검색하고, 방문객 규모와 대중교통 접근성 등의 데이터를 시각적으로 분석할 수 있도록 구현했습니다.

또한 머신러닝 모델을 활용하여 사용자가 입력한 축제 조건을 기반으로 **예상 방문객 수를 예측**하고, 예측 결과를 현재 축제 데이터의 방문객 규모와 비교하여 확인할 수 있도록 구성했습니다.

### 프로젝트 목표

* 전국 축제 정보를 조건별로 검색
* 축제 개최 기간에 따른 방문객 추이 분석
* 지하철 및 버스 등 대중교통 인프라와 방문객 수의 관계 분석
* 주요 축제의 방문객 규모 비교
* 축제 조건을 기반으로 방문객 수 예측
* 축제 기획 및 운영에 활용할 수 있는 데이터 기반 정보 제공

---

## 🖥️ 주요 기능

### 1. 🔎 축제 정보 검색

축제명, 개최 지역, 개최 기간, 지하철 연계 여부 등의 조건을 이용하여 원하는 축제를 검색할 수 있습니다.

검색 결과에는 다음과 같은 정보가 제공됩니다.

* 축제명
* 광역시도
* 개최장소
* 축제 시작일 / 종료일
* 주관기관
* 방문객 수
* 버스정류장 수
* 지하철 연계 여부
* 전화번호

검색 결과가 많은 경우 최대 500건을 화면에 표시하며, 전체 검색 결과는 CSV 파일로 다운로드할 수 있습니다.
또한 `st.form`을 사용하여 여러 검색 조건을 변경할 때마다 필터링이 실행되는 것을 방지하고, **검색 버튼을 클릭했을 때 한 번에 검색이 수행되도록 구현**했습니다.

---

### 2. 📊 기간 및 대중교통 인프라 추이 분석

축제 데이터를 기반으로 기간별 방문객 추이와 지역별 방문객 규모를 분석합니다.

대중교통 접근성에 따라 다음 조건을 선택할 수 있습니다.

* 전체 축제
* 지하철 연계 축제
* 인근 버스정류장 5개 이상인 축제

이를 기준으로 **축제 시작일별 방문객 추이**와 **광역시도별 평균 방문객 수**를 확인할 수 있습니다.

또한 방문객 수가 많은 주요 축제를 선택하여 축제별 방문객 규모를 직접 비교할 수 있습니다.

---

### 3. 🎪 축제명 및 개최장소 검색

축제명 또는 개최장소/지역을 키워드로 입력하여 관련 축제를 검색할 수 있습니다.

검색 결과와 함께 검색된 축제들의 **평균 행사기간**을 확인하여 축제 기획에 참고할 수 있도록 구성했습니다.

---

### 4. 🎯 방문객 수 예측

저장된 머신러닝 모델(`festival_model.joblib`)을 활용하여 축제 조건에 따른 예상 방문객 수를 예측합니다.

사용자가 입력하는 주요 조건은 다음과 같습니다.

| 입력 변수  | 설명            |
| ------ | ------------- |
| 행사기간   | 축제 개최 기간      |
| 버스정류장수 | 인근 버스정류장 수    |
| 지하철유무  | 지하철 연계 여부     |
| 홈페이지주소 | SNS 및 홈페이지 유무 |

입력값을 기반으로 1개의 데이터 행을 생성한 뒤 저장된 모델을 이용하여 방문객 수를 예측합니다.

예측 결과는 예상 방문객 수와 함께 데이터의 방문객 규모 기준으로 표시됩니다.

* 상대적으로 적은 규모
* 평균적인 규모
* 큰 규모
* 매우 큰 규모

현재 구현에서는 방문객 수의 기준값으로 `q25 : 633,445`, `q50 : 867,112`, `q75 : 1,355,700`을 사용하고 있습니다.

## 🧠 데이터 분석

본 프로젝트에서는 축제 데이터를 활용하여 다음과 같은 분석을 수행합니다.

### 방문객 추이 분석

축제 시작일을 기준으로 방문객 수를 집계하여 기간에 따른 방문객 변화를 확인합니다.

### 지역별 분석

광역시도별 평균 방문객 수를 계산하여 지역별 축제 방문객 규모를 비교합니다.

### 교통 접근성 분석

지하철 연계 여부 및 버스정류장 수를 기준으로 축제를 분류하여 대중교통 인프라와 방문객 규모의 관계를 확인합니다.

### 주요 축제 비교

방문객 수가 많은 상위 축제를 선정하고, 사용자가 원하는 축제를 선택하여 방문객 규모를 비교합니다.

## 🤖 머신러닝 예측

### 사용 모델

저장된 `festival_model.joblib` 모델을 활용합니다.

모델은 별도의 모델 생성 과정에서 저장된 전처리 및 모델을 그대로 불러와 Streamlit 화면에서 예측에 사용합니다.

### 예측 과정

```text
사용자 입력
    ↓
축제 조건 데이터 생성
    ↓
저장된 머신러닝 모델 로드
    ↓
방문객 수 예측
    ↓
예상 방문객 수 출력
    ↓
방문객 규모 분석
```
