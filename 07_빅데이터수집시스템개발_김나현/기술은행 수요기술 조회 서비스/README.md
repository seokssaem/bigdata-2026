# NTB API 데이터 수집 프로젝트

## 프로젝트 소개

공공데이터포털에서 제공하는 **한국산업기술진흥원(KIAT) 기술은행 수요기술 조회 서비스 API**를 활용하여 기술 수요 데이터를 수집하고 분석 가능한 형태로 전처리하는 프로젝트이다. 수집한 데이터는 PostgreSQL과 CSV 파일에 저장하여 추후 데이터 분석 및 시각화에 활용할 수 있도록 구성하였다.

## 데이터 수집 과정

프로젝트는 다음과 같은 순서로 데이터를 수집하고 저장한다.

1. 공공데이터포털 API를 호출한다.
2. XML 형식의 응답 데이터를 수신한다.
3. XML 데이터를 Dictionary 형태로 변환한다.
4. 전체 페이지를 반복 조회하여 데이터를 수집한다.
5. 수집된 데이터를 DataFrame으로 변환한다.
6. 영문 컬럼명을 한글 컬럼명으로 변경한다.
7. 분석을 위한 파생 컬럼을 생성한다.
8. PostgreSQL 데이터베이스에 저장한다.
9. CSV 파일로 저장한다.

---

## 데이터 전처리

### 컬럼명 변경

API에서 제공하는 영문 컬럼명을 분석하기 쉬운 한글 컬럼명으로 변경하였다.

| API 컬럼      | 변경 컬럼  |
| ----------- | ------ |
| buyKindNm   | 희망구매유형 |
| dmdtchNm    | 수요기술명  |
| hopepcEraCd | 구매희망시기 |
| keyword     | 키워드    |
| tpDmandCdNm | 기술센터지역 |

### 파생 컬럼 생성

데이터 활용성을 높이기 위해 다음과 같은 파생 컬럼을 생성하였다.

| 컬럼명   | 설명                                              |
| ----- | ----------------------------------------------- |
| 수집일시  | 데이터를 수집한 날짜 및 시간을 저장한다.                         |
| 정보충실도 | 기술개요, 키워드, 기술구매조건, 계약유형의 입력 여부를 기반으로 정보를 정량화한다. |

## 데이터 저장

수집한 데이터는 PostgreSQL 데이터베이스와 CSV 파일에 저장한다.

### PostgreSQL

* 테이블명 : `ntb_data`

### CSV

* 저장 경로 : `output/NTB_data.csv`
* 인코딩 : UTF-8(BOM)

## 실행 방법

1. `.env` 파일을 생성한다.

```env
NTB_API_KEY=발급받은_API_KEY
```

2. 필요한 라이브러리를 설치한다.

```bash
pip install pandas requests xmltodict sqlalchemy psycopg2 python-dotenv lxml
```

3. PostgreSQL 데이터베이스를 생성한다.

4. `NTB_API.ipynb`를 실행한다.
