# 탐색적데이터분석

## 분석 과정 요약
1. 데이터 기초 특성 파악
    - (행, 열) 파악
    - 컬럼별 타입 파악
    - 통계량 파악

2. 단변량/분포 시각화
    - 히스토그램 → 월평균구매금액 분포 확인
    - 막대그래프 → 쿠폰사용여부 건수 분포 확인
    
3. 상관관계 및 이변량 분석
    - heatmap → 수치형 변수 간 상관계수 행렬 확인
    - scatterplot → 상관관계가 가장 높은 구매횟수와 리뷰점수 관계 확인
    - boxplot → 멤버십등급별 구매횟수 확인

4. 그룹별 비교 분석 및 인사이트 도출 
    - 막대그래프 → 멤버십등급별 월평균구매금액 평균 확인
    - 막대그래프 → 멤버십등급별 구매횟수 평균 확인

## 시각화 결과에 대한 해석 및 인사이트 정리
- 단변량/분포 시각화
    - 월평균구매금액은 200,000원 이하에 치우쳐져 있으며, 높은 금액 쪽에 이상치로 볼 수 있는 데이터가 소수 있지만 충분히 존재할 수 있는 데이터이다.
    - 구매 시 쿠폰을 사용 하지 않은 사람들이 더 많다.

- 상관관계 및 이변량 분석
    - 구매횟수와 리뷰점수의 상관관계가 가장 높고, 나이와 구매횟수의 상관관계가 가장 낮다.
    - 하지만 무조건 구매를 많이 했기 때문에 리뷰점수가 높고, 나이가 많기 때문에 구매횟수가 높다고 볼 수는 없다.
    - 구매를 1번 했어도 리뷰점수를 5점 줄 수 있고, 나이가 많아도 쇼핑을 즐기지 않는다면 구매횟수가 적을 수 있다.

- 그룹별 비교 분석 및 인사이트 도출 
    - 멤버십등급이 높을수록 월평균구매금액과 구매횟수가 높다.
    - 구매횟수와 리뷰점수의 상관관계를 보았을 때, 구매횟수가 많을수록 리뷰점수가 높은 쪽에 많이 분포되어 있다.
