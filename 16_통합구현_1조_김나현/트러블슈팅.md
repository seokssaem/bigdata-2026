## Docker Compose 트러블슈팅
### 1. Docker 이미지 빌드 시 BuildKit gRPC 오류
### 문제 상황

Docker Compose로 FastAPI와 Streamlit 이미지를 빌드하는 과정에서 다음 오류가 발생

```
http2: server: error reading preface from client
//./pipe/dockerDesktopLinuxEngine: file has already been closed

failed to dial gRPC:
header key "x-docker-expose-session-sharedkey"
contains value with non-printable ASCII characters
```

### 원인 분석

프로젝트가 저장된 경로에 한글이나 특수문자와 같은 비 ASCII 문자가 포함

### 해결 방법

프로젝트 폴더를 한글이나 특수문자가 없는 영문 경로로 이동

### 2. 컨테이너에서 API 키 및 PostgreSQL 환경변수 인식 실패
### 문제 상황

Docker Compose로 컨테이너를 실행한 후, Streamlit 화면에서 KOBIS API 키가 설정되지 않았다는 오류가 발생
```
.env 파일에 KOBIS_API_KEY가 설정되어 있지 않습니다.
```

### 원인 분석

로컬 .env 파일에 API 키와 PostgreSQL 접속 정보를 작성했지만, 해당 값이 컨테이너 내부 환경변수로 전달되지 않음

컨테이너는 호스트 환경과 분리되어 있으므로 필요한 환경변수를 docker-compose.yml을 통해 명시적으로 전달해야함

### 해결 방법

먼저 .env 파일에 KOBIS API 키와 PostgreSQL 접속 정보를 설정
```
KOBIS_API_KEY=발급받은_API_KEY

POSTGRES_USER=postgres
POSTGRES_PASSWORD=비밀번호
POSTGRES_DB=movie_db
```
이후 docker-compose.yml의 environment 항목을 통해 환경변수를 각 컨테이너에 전달
```yaml
services:
  web:
    build: .
    container_name: movie-web
    ports:
      - "8501:8501"
    environment:
      KOBIS_API_KEY: ${KOBIS_API_KEY}
      API_URL: http://api:8000
    depends_on:
      - api

  api:
    build: ./api
    environment:
      KOBIS_API_KEY: ${KOBIS_API_KEY}
      DATABASE_URL: postgresql://postgres:${POSTGRES_PASSWORD}@db:5432/movie_db
    depends_on:
      - db

  db:
    image: postgres:17
    environment:
      POSTGRES_USER: ${POSTGRES_USER}
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}
      POSTGRES_DB: ${POSTGRES_DB}
```

### 결과

- KOBIS API 키와 PostgreSQL 접속 정보가 각 컨테이너에 정상적으로 전달됨
- 이에 따라 실시간 영화 정보 조회와 데이터베이스 연결이 정상적으로 동작함

### 3. Streamlit 컨테이너에서 FastAPI 연결 실패
### 문제 상황

이미지 빌드와 컨테이너 실행에는 성공했지만, Streamlit에서 FastAPI를 호출할 때 다음 오류가 발생
```
requests.exceptions.ConnectionError
File "/.../requests/adapters.py", line , in in send
    raise ConnectionError(e, request=request)
```
### 원인 분석

Streamlit에서 FastAPI 주소를 다음과 같이 지정한 것이 원인
```
API_BASE = "http://127.0.0.1:8000"
```
Docker 컨테이너 내부에서 127.0.0.1 또는 localhost는 호스트 PC나 다른 컨테이너가 아니라 현재 실행 중인 컨테이너 자신을 의미

따라서 Streamlit 컨테이너가 FastAPI 컨테이너가 아닌 자기 자신에게 요청을 보내면서 연결 실패

### 해결 방법

Docker Compose가 제공하는 내부 네트워크와 서비스 이름을 이용하도록 API 주소를 변경

FastAPI 서비스 이름이 api인 경우:
```python
import os

API_BASE = os.getenv("API_BASE", "http://api:8000")
```

compose.yml의 Streamlit 서비스에도 API 주소를 환경변수로 설정

```yaml
services:
  api:
    build: ./api
    ports:
      - "8000:8000"
    command: uvicorn main:app --host 0.0.0.0 --port 8000

  web:
    build: ./web
    ports:
      - "8501:8501"
    environment:
      API_BASE: http://api:8000
    depends_on:
      - api
```
