# 분석데이터전처리

## 처리 과정 요약 및 판단 근거
1. 데이터 불러오기 및 결측치 처리
    - 데이터 info 확인
    - 컬럼별 결측치 개수 확인
    - 결측치가 존재하는 수치형 변수 컬럼 ['나이', '리뷰점수'] → 평균값 대체
    - 결측치가 존재하는 범주형 변수 컬럼 ['성별', '가입경로'] → 최빈값 대체
    - 결측치 제거 확인

2. 이상치 탐지 및 처리
    - boxplot → 구매횟수 분포 확인
    - 구매횟수 이상치의 하한/상한 경계값 계산
    - 이상치를 계산된 경계값으로 대체
        - 아예 말이 안 되는 값이 아니면서, 기존 최대값과 상한의 차이가 적기 때문에

3. 범주형 변수 인코딩
    - ['성별', '거주지역', '가입경로', '쿠폰사용여부'] 컬럼 원-핫 인코딩
        - 모두 순서 의미 없는 범주이기 때문에
    - 인코딩 전/후의 데이터프레임 형태와 컬럼 목록을 비교
    
4. 파생변수 생성 및 스케일링
    - 월평균구매금액과 구매횟수 컬럼을 조합하여 1회당평균구매금액 파생변수 생성
    - StandardScaler → 이탈여부 제외한 수치형 변수 스케일링
    - 스케일링 전/후 기술통계량을 비교
    - 최종 전처리 완료 데이터를 `prj_data_cleaned.csv`로 저장
