# 공항 혼잡도 데이터 적재 및 검증 파이프라인 구축

## 프로젝트 개요
수집된 공항별 혼잡도 CSV 데이터를 분석하여 시계열 누적 구조에 맞는 복합 기본키 테이블을 설계하고, 대량 적재 최적화 및 원본 대비 데이터의 완전성을 검증하는 자동화 파이프라인 프로그램

## 수행 내용
- `models.py`: 시계열 데이터 유실 방지를 위해 공항코드 + 수집시간 + 수집일시 조합의 복합 기본키(Composite PK) 엔티티 설계
- `database.py`: SQLAlchemy 기반의 PostgreSQL 연결 엔진 설정 및 파이프라인 시작 시 테이블을 자동 생성하는 초기화(init_db) 구현
- `loader.py`: Pandas를 통한 날짜 포맷팅 정제 후, 중복 방지를 위한 자연키 기반 db.merge()(Upsert) 적재 및 1,000건 단위 분할 커밋 최적화
- `verify.py`: 원본 CSV 행 수와 DB 적재 건수를 대조하는 완전성 검증, 전체_혼잡도 결측치(NULL) 집계, 혼잡여부 도메인 외 이상치 필터링 기능 구현
- `pipeline.py`: 데이터베이스 초기화, CSV 적재, 적재 무결성 검증 단계를 일원화하여 순차 실행을 보장하는 통합 제어
