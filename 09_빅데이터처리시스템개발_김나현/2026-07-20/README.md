# 기술은행 데이터 배치 및 이벤트 처리 시스템

## 프로젝트 소개

본 프로젝트는 PostgreSQL에 저장된 기술은행 데이터를 대상으로 배치 처리(Batch Processing)와 이벤트 처리(Event Processing)를 수행하는 데이터 처리 시스템이다.

배치 처리에서는 전체 데이터를 집계하여 분석용 테이블을 생성하고, 이벤트 처리에서는 데이터 품질 및 이상 조건을 탐지하여 별도의 이벤트 테이블에 저장한다. 마지막으로 검증 모듈을 통해 생성된 결과 테이블을 확인하여 전체 처리 과정의 정상 수행 여부를 검증한다.

---

## 프로젝트 구조

```text
.
├── config.py                # 데이터베이스 접속 정보 설정

```

## 주요 기능

### 1. 데이터베이스 연결

`config.py`에서는 환경 변수 또는 기본 URL을 이용하여 PostgreSQL 접속 정보를 설정한다. `database.py`에서는 SQLAlchemy Engine을 생성하고 공통적으로 사용하는 데이터베이스 유틸리티 함수를 제공한다.
주요 기능은 다음과 같다.

* PostgreSQL 연결
* 테이블 존재 여부 확인
* 테이블 행 수 조회
* SQL 스크립트 실행

---

### 2. 배치 처리

배치 처리는 전체 기술 데이터를 대상으로 집계 테이블을 생성한다. 데이터 계산은 Python이 아닌 PostgreSQL에서 수행하도록 구현하여 대용량 데이터 처리 효율을 높였다.

생성되는 집계 테이블은 다음과 같다.

| 테이블                 | 설명                      |
| ------------------- | ----------------------- |
| tech_region_summary | 지역별 기술 수요 건수 및 평균 정보충실도 |
| tech_status_summary | 진행상태별 기술 수요 건수          |

배치 처리 과정은 다음과 같다.

1. 원본 테이블 존재 여부 확인
2. 지역별 집계 생성
3. 진행상태별 집계 생성
4. 처리 완료

---

### 3. 이벤트 처리

이벤트 처리는 데이터 품질 관리 및 이상 상황 탐지를 목적으로 수행한다. 조건을 만족하는 데이터를 탐지하여 이벤트 알림 테이블에 저장한다.

구현한 이벤트는 다음과 같다.

| 이벤트                  | 설명                              |
| -------------------- | ------------------------------- |
| TECH_FEE_NEGOTIATION | 정액기술료 또는 경상기술료가 '협의후 결정'인 기술 탐지 |
| LOW_INFORMATION      | 정보충실도가 임계값 이하인 기술 탐지            |

이벤트 발생 시 다음 정보를 저장한다.

* 이벤트 종류
* 수요기술번호
* 수요기술명
* 이벤트 상세 내용
* 탐지 시각

기존 이벤트를 삭제한 후 다시 생성하는 방식으로 구현하여 동일한 처리를 반복 수행하더라도 결과가 일관되도록 멱등성을 보장하였다.

---

### 4. 결과 검증

배치 처리와 이벤트 처리 완료 후 생성된 테이블을 검증한다. 검증 단계에서는 각 테이블의 존재 여부와 데이터 건수를 확인하며, 하나라도 조회에 실패하면 전체 결과를 FAIL로 판정한다.

검증 대상은 다음과 같다.

* tech_region_summary
* tech_status_summary
* missing_fee_event_alerts
* low_information_event_alerts

---

## 처리 흐름

```text
기술은행 데이터(tech)
        │
        ▼
원본 테이블 확인
        │
        ▼
배치 처리
 ├─ 지역별 집계
 └─ 진행상태별 집계
        │
        ▼
이벤트 처리
 ├─ 기술료 미기재 탐지
 └─ 정보충실도 부족 탐지
        │
        ▼
결과 검증
        │
        ▼
처리 완료
```

## 실행 방법

### 배치 처리

```bash
python batch_processor.py
```

### 이벤트 처리

```bash
python event_processor.py --tech-threshold 1
```

`--tech-threshold` 옵션을 사용하여 정보충실도 이벤트의 임계값을 변경할 수 있다.

### 결과 검증

```bash
python verify_processing.py
```

* PostgreSQL 기반 배치 처리 구현
