# 고객 이탈 데이터 전처리 결과 요약

## 1. 결측치 처리
- 결측 비율 확인: 메모 56.8%, 나이 8.0%, 리뷰점수 5.0%, 가입경로 4.0%, 성별 3.0%
- 메모 컬럼은 결측 비율이 50%를 초과하여 삭제
- 수치형(나이, 리뷰점수)은 중앙값으로 대체
- 범주형(성별, 가입경로)은 최빈값으로 대체
- 이유: 월평균구매금액처럼 극단값의 영향을 받는 컬럼이 존재해, 평균보다 중앙값이 더 안정적인 대표값이라 판단
- 처리 후 isnull().sum()으로 전 컬럼 결측치 0건 확인

## 2. 이상치 탐지 및 처리
- 대상 변수: 월평균구매금액
- IQR 계산 결과: Q1=48,362.46 / Q3=114,551.10 / IQR=66,188.64
- 상한 초과 이상치 12건 발견
- 처리 방식: 제거하지 않고 경계값으로 대체(capping)
- 이유: 표본 수가 크지 않아 행 삭제 시 다른 컬럼 정보까지 손실되고, 고액 구매 기록이 입력 오류가 아닌 실제 VIP성 고객일 가능성이 있어 완전히 버리기보다 분포 영향력만 줄이는 capping을 선택

## 3. 범주형 변수 인코딩
- 인코딩 전 shape: (500, 11) → 인코딩 후 shape: (500, 20)
- 멤버십등급: 브론즈(0) < 실버(1) < 골드(2) < VIP(3) — 서열이 있는 순서형 변수라 레이블 인코딩 적용
- 성별, 거주지역, 가입경로, 쿠폰사용여부: 서열이 없는 명목형 변수 — 레이블 인코딩 시 존재하지 않는 크기·순서 관계를 모델이 학습할 위험이 있어 원-핫 인코딩 적용

## 4. 파생변수 생성 및 스케일링
- 파생변수: 회당평균구매금액 = 월평균구매금액 ÷ 구매횟수 (고객 1회 결제당 평균 지출 규모)
- StandardScaler로 나이, 월평균구매금액, 구매횟수, 리뷰점수, 회당평균구매금액을 표준화
- 스케일링 후 각 변수의 평균이 약 0, 표준편차가 약 1로 변환된 것을 describe()로 확인
- 최종 전처리 데이터를 prj_data_cleaned.csv로 저장
