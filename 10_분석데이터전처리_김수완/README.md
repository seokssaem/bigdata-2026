# 고객 이탈 데이터 전처리 프로젝트

`prj_data.csv` 결측치 처리, 이상치 처리, 범주형 인코딩, 파생변수 생성 및 스케일링을 수행하고 `prj_data_cleaned.csv`로 저장했다. 전체 코드는 `10_분석데이터전처리.ipynb`이다.

---

## 1. 결측치 처리

- `info()` / `isnull().sum()` 확인 결과, 나이(8.0%), 성별(3.0%), 가입경로(4.0%), 리뷰점수(5.0%), 메모(56.8%)에 결측치 존재.
- 메모: 결측 비율이 50%를 초과하여 대체 대신 **컬럼 삭제**.
- 나이, 리뷰점수(수치형): 평균으로 대체.
- 성별, 가입경로(범주형): 최빈값으로 대체.
- 처리 후 `isnull().sum()`으로 전 컬럼 결측치 0건을 재확인.

판단 근거: 결측 비율이 50%를 넘는 컬럼(메모)은 대체 시 절반 이상이 하나의 대표값으로 채워져 분석 왜곡 위험이 크므로 삭제가 합리적이다.

---

## 2. 이상치 탐지 및 처리

- '월평균구매금액'을 boxplot으로 시각화하여 이상치 존재 확인.
- IQR 기법 적용: 하한 = Q1 − 1.5×IQR, 상한 = Q3 + 1.5×IQR
- 경계값을 벗어난 12건을 삭제하지 않고 경계값으로 대체(capping).

판단 근거: 이상치 비율이 낮지만(2.4%), 행 전체를 삭제하면 다른 컬럼의 정상적인 정보까지 함께 손실된다. 따라서 극단값의 영향력만 완화하는 capping 방식을 선택했다.

---

## 3. 범주형 변수 인코딩

| 변수 | 순서 의미 | 인코딩 방식 |
|---|---|---|
| 멤버십등급 | 있음 (브론즈<실버<골드<VIP) | 레이블 인코딩 (직접 매핑) |
| 성별, 거주지역, 가입경로, 쿠폰사용여부 | 없음 | 원-핫 인코딩 (`pd.get_dummies`) |

- 인코딩 전: `(500, 11)` → 인코딩 후: `(500, 20)`
- 멤버십등급은 등급 간 순위 관계가 있어 정수 0~3으로 변환했다. 이때 sklearn의 `LabelEncoder`는 값을 알파벳순으로 자동 정렬해 원하는 등급 순서를 보장하지 못하므로, `{'브론즈':0, '실버':1, '골드':2, 'VIP':3}` 형태의 딕셔너리를 직접 매핑했다.
- 성별·거주지역·가입경로·쿠폰사용여부는 값 사이에 크기·순서 관계가 없는 변수이므로 원-핫 인코딩을 적용했다.

---

## 4. 파생변수 생성 및 스케일링

- 건당평균구매금액 = 월평균구매금액 ÷ 구매횟수 → 1회 구매당 평균 지출액을 나타내는 지표.
- 연령대 = 나이를 10대~60대이상 구간으로 범주화 → 연령대별 이탈 패턴 분석에 활용.
- 나이, 월평균구매금액, 구매횟수, 리뷰점수, 건당평균구매금액에 `StandardScaler` 적용.
- 스케일링 전/후 `describe()`로 평균·표준편차 변화를 비교해 정상적으로 반영됐음을 확인.

판단 근거: 월평균구매금액(수만~수십만 단위)과 리뷰점수(0~5 범위)처럼 컬럼 간 값의 범위 차이가 커서, 스케일을 맞추지 않으면 특정 변수가 분석·모델링에 과도한 영향을 줄 수 있다. 이에 표준화(StandardScaler)를 적용해 변수 간 영향력 균형을 맞췄다.
