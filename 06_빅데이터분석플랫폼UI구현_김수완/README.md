고속도로 교통정보 UI
- HTML, CSS, JavaScript와 Chart.js를 활용하여 고속도로 교통정보를 시각화한 웹 플랫폼입니다.

사용 데이터 출처
- 공공데이터포털
- 한국도로공사 교통정보 Open API

API 안내 URL
- https://www.data.ex.co.kr



구현 기능
- 고속도로 교통정보 대시보드 화면 구성
- 핵심 통계 카드 표시 (평균 속도, 최대 교통량, 평균 통행시간, 전체 구간 수)
- Chart.js를 이용한 막대그래프 (구간별 교통량)
- Chart.js를 이용한 선그래프 (구간별 평균속도)
- 구간별 교통정보 표(Table) 표시
- 반응형 레이아웃 적용

실행방법
1. index.html 파일과 style.css 파일을 같은 폴더에 저장합니다.
2. index.html 파일을 더블클릭하여 실행합니다.
3. Chrome, Edge, Firefox 등 최신 브라우저에서 확인할 수 있습니다.
