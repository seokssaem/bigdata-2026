## 4. 결측치 처리와 데이터 분리

- `insulin` 결측치를 왜 평균이 아니라 중앙값으로 채웠나요?
    - `insulin`의 평균은 이상치에 영향을 받기 쉬운 값이기 때문이다
- 결측치를 전체 데이터에서 먼저 채우는 것과 훈련 데이터에서 계산한 중앙값으로 채우는 것은 어떤 차이가 있을까요?
    - 전체 데이터에서 결측치를 먼저 채우면 데이터 누수가 발생한다 반면 훈련 데이터에서 계산한 중앙값을 계산하고 검증 데이터에 동일하게 적용하면 더 공정하고 현질적으로 평가할 수 있다.
- `stratify=y`를 사용한 이유는 무엇인가요?
    - `y`를 기준으로 비율을 나누어 훈련 세트와 검증 세트에서도 동일하게 유지되도록 하기 위함이다

## 7. 혼동 행렬과 당뇨 클래스 성능

- True Negative, False Positive, False Negative, True Positive의 개수를 적어보세요.
    -	|   | 예측_0 |	예측_1 |
        | ---| --- | --- |
        | 실제_0 | 95 |	23 |
        | 실제_1 | 39 |	43 |

- 당뇨 예측에서 False Negative는 어떤 상황인가요?
    - 실제 당요병 환자이지만 모델이 당요병이 아니다라고 잘못 예측한 상황이다
- 이 서비스에서는 Precision과 Recall 중 어느 지표를 더 중요하게 볼지 자신의 생각을 적어보세요.
    - Recall이 더 중요하다고 생각한다. 실제 당뇨병 환자를 정상이라고 오진하는 경우가 더 위험하기 때문에 당뇨병 가능성이 있는 사람을 최대한 놓치지 않고 걸러내는 것이 이 서비스의 목적에 더 부합한다고 생각한다.
- Precision, Recall, F1-score가 각각 무엇을 의미하는지 본인 말로 설명해보세요.
    - `Precision` : 정밀도 -> 당뇨라고 예측한 사람이 진짜 당뇨인 비율
    - `Recall` : 재현율 -> 실제 당뇨인 사람들 중 모델이 제대로 찾아낸 비율
    - `F1-score` : 평균 조화 -> 한쪽을 올리면 다른 쪽이 떨어지는 트레이드오프 관계인 `Precision`과 `Recall`이 둘을 하나의 숫자로 균형 있게 요약해서 보여주는 지표

## 9. 딥러닝 학습 과정

- 출력층에서 `sigmoid`를 사용한 이유는 무엇인가요?
    - `sigmoid`를 사용해 함수의 입력값을 0~1 사이의 값으로 압축하고 임계값 `0.5`을 적용해 최종적으로 0 또는 1로 분류하기 위해서이다
- 손실 함수로 `binary_crossentropy`를 사용한 이유는 무엇인가요?
    - `binary_crossentropy`는 두 개의 클래스를 분류하는 문제에 특화된 함수이다. 이 함수를 사용하여 예측한 확률이 실제 정답과 얼마나 차이가 나는지 측정하고 차이가 클 수록 손실을 크게 부여하여 정답에 가까운 확률을 출력하도록 유도하는 데 적합하기 떄문이다.
- Dropout(0.3)은 어떤 문제를 줄이기 위해 사용했나요?
    - 과적합을 줄이기 위해 사용하였다.
- 최고 검증 Accuracy가 나온 epoch와 마지막 epoch의 Accuracy는 같았나요?
    - 같지 않다. 최고 검증 6번 째에는 0.71 마지막 검증엔 0.69 6번 째 이후로 최고점을 넘지 못했다.
- 마지막 학습 Accuracy와 검증 Accuracy 차이가 크다면 무엇을 의심할 수 있나요?
    - 과적합을 의심할 수 있다
