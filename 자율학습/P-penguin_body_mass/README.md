# 프로젝트 보고서
관측이 쉬운 펭귄의 신체 특성(부리 길이,날개 길이 등)만으로 체중(body_mass_g)을 예측하는 회귀 프로젝트입니다. 직접 포획해서 체중을 재는 대신 모델 예측값으로 대체해, 현장 조사 시간과 개체 스트레스를 줄이는 것을 목표로 합니다.

`python 3.12`
`scikit-learn`
`TensorFlow/Keras`
`pandas`
`seaborn`
`matplotlib`


## 배경 및 문제 정의
- **도메인** : 생태/자연과학 (남극 페우긴 개체 조사)
- **문제 유형**: 회귀(Regression) - 타겟이 연속값(g단위 체중)이기 때문
- **타켓 변수**: `body_mass_g`
- **입력 변수**: 종(`species`), 서식 섬(`island`), 부리 길이/ 깊이, 날개 길이, 성별


## 데이터
| 항목 | 내용 | 
| --- | --- |
| 크기 | 500행 x 7열 |
| 결측치 | `sex` 컬럼 25개 (최빈값 `Male`으로 대체) |
| 범주형 처리 | `species`, `island` , `sex` -> One-Hot Encoding(`drop_first=True`) |
| 인코딩 후 컬럼 수 | 9개 |
| Train / Valid | 400 / 100 (`test_size=0.2`, `random_state42`) |

**주요 컬럼**
| 컬럼 | 설명 |
| --- | --- |
| `species` | 펭귄 종 (Adelie, Chinstrap, Gentoo) |
| `island` | 서식 섬 (Biscoe, Dream, Torgersen) |
| `bill_length_mm` | 부리 길이(mm) |
| `bill_depth_mm` | 부리 깊이 (mm) |
| `flipper_length_mm` | 날개 길이 (mm) |
| `sex` | 성별 |
| `body_mass_g` | **예측 대상**, 체중(g) |


## 파이프라인
```
1. EDA : 종별 평균 체중 비교, 날개 길이-체중 상관관계 확인
2. 전처리 : 결측치(최빈값) -> One-Hot Encoding -> Train/Valid 분리 -> StandardScaler
3. 모델링 : LinearRegression / FandomForestRegressor / Keras DNN
4. 평가 : MAE, R2 score 비교 + 특성 중요도 분석
```

## 3. 전처리 과정에서 고민한 점

- `sex` 결측치를 왜 평균이 아니라 최빈값으로 채웠나요?
    - `sex`의 값은 남,여 두가지로 되어 있어 최빈값으로 채운다
- `species`, `island`, `sex`를 그대로 모델에 넣지 못하는 이유는 무엇인가요?
    - 머신러닝은 숫자만 이해할 수 있는데 세개의 컬럼은 범주형 데이터이기 때문이다.
- `pd.get_dummies(drop_first=True)`의 `drop_first=True`는 어떤 역할을 하나요?
    - 각 범주형 컬럼의 첫번째 카테고리를 삭제한다 -> n-1개로도 모든 정보를 표현할 수 있기 때문
- 원-핫 인코딩 후 컬럼 수가 어떻게 바뀌었나요?
    - 9개

## 4. 훈련·검증 데이터와 스케일링

- 데이터를 훈련용과 검증용으로 나누는 이유는 무엇인가요?
    - 본 적 없는 데이터로도 잘 작동하는지 확인하기 위해
- 검증 데이터에 `fit_transform()`이 아니라 `transform()`만 사용한 이유는 무엇인가요?
    - fit_transform : 한 번에 학습 + 적용
    - transform : 이미 학습된 기준을 그대로 적용만 할 데이터
- RandomForest도 반드시 스케일링해야 할까요? 찾아본 내용을 적어보세요.
    - 필수 x -> (대소 비교 분기는 순서만 중요하지 값 자체의 절대적 크기나 단위가 결과에 영향을 주지 않기 때문)

## 7. 딥러닝 학습 과정

- 출력층에 `Dense(1, activation='linear')`를 사용한 이유는 무엇인가요?
    - 예측하려는 값이 `body_mass_g` 하나이기 때문
- `mse`와 `mae`는 각각 어떤 역할로 사용되었나요?
    - `mse`(손실 함수) : 최소화하려는 목표값, 큰 오차에 더 크게 패널티를 줘서 큰 실수를 특히 줄이려는 방향으로 학습
    - `mae`(평가 지표) : 사람이 보기 편하도록 모니터링하는 지표
- EarlyStopping은 왜 사용했나요?
    - `val_loss(검증 손실)`가 `patience=10`에폭 동안 개선되지 않으면 자동으로 멈추기 위해서 -> 과적합 방지, 불필요한 학습 시간 절약
- 가장 낮은 검증 Loss가 나온 epoch와 마지막 epoch가 달랐나요?
    - 100으로 동알
- 학습 Loss와 검증 Loss 그래프에서 과적합 징후가 보였나요?
    - 과적합 징후 안 보임
