# ⚾ KBO 타자 기록 기반 OPS 예측 모델

## 1. 프로젝트 소개

### 프로젝트명

**타자의 경기 기록을 이용한 OPS 예측 모델 개발**

### 프로젝트 목적

KBO 타자의 기본 경기 기록을 활용하여 타자의 공격력을 나타내는 대표적인 지표인 `OPS(On-base Plus Slugging)`를 예측하는 머신러닝 회귀 모델을 개발한다.

데이터 전처리부터 모델 학습 및 평가까지의 과정을 하나의 분석 파이프라인으로 구성하고, 분석 코드를 함수 및 모듈 단위로 분리하여 유지보수와 재실행이 쉽도록 구현하는 것을 목표로 한다.

---

## 2. 분석 문제 정의

OPS는 타자의 공격력을 종합적으로 평가하는 대표적인 지표이다.

본 프로젝트에서는 타자의 타석, 타수, 안타, 홈런, 볼넷 등의 기본 경기 기록을 독립변수로 사용하여 OPS를 예측하는 머신러닝 모델을 구축한다.

### 분석 가설

* **H0(귀무가설)**: 타자의 기본 기록은 OPS 예측에 유의한 영향을 미치지 않는다.
* **H1(대립가설)**: 타자의 기본 기록은 OPS 예측에 유의한 영향을 미친다.

## 5. 프로젝트 구조
전처리 → 모델 학습 → 평가 과정을 하나의 파이프라인으로 구조화하고, 각 단계를 함수/모듈 단위로 분리해
유지보수와 재실행이 쉽도록 구성하였다. scikit-learn을 기반으로 구현하였다.

```text
kbo_ops/
├── hitter.csv
├── README.md
├── main.py               # 실행하는 py
└── ops_pipeline/         # 분석 로직 모듈
    ├── config.py         # 공통 설정값 (경로, 변수 목록, 하이퍼파라미터)
    ├── preprocessing.py  # 1단계: 데이터 로드 & 전처리
    ├── models.py         # 2단계: 데이터 분할 & 모델 학습 (선형회귀 / RandomForest)
    ├── evaluate.py         # 3단계: 성능 평가 (MAE, RMSE, R2, 5-Fold 교차검증)
    ├── visualize.py        # 시각화 함수 (분포, 상관관계, 예측 비교, 변수 중요도)
    ├── __init__.py         # 패키지 초기화 
    └── pipeline.py         # 전처리→학습→평가를 하나로 묶은 파이프라인
```

## 11. 모델 평가

모델의 성능은 다음 세 가지 지표를 이용하여 평가하였다.

### MAE (Mean Absolute Error)

실제값과 예측값 차이의 절댓값 평균으로, **값이 작을수록 좋은 모델**을 의미한다.

### RMSE (Root Mean Squared Error)

예측 오차를 제곱하여 평균을 계산한 후 다시 제곱근을 적용한 값으로, **값이 작을수록 좋은 모델**을 의미한다.

### R² (결정계수)

모델이 종속변수의 변동을 얼마나 설명하는지를 나타내며 일반적으로 **1에 가까울수록 설명력이 높은 모델**을 의미한다.

추가적으로 **5-Fold Cross Validation**을 이용하여 특정 Train/Test 데이터 분할에만 의존하지 않고 모델의 일반화 성능을 평가하였다.

### 성능 평가 결과
| 모델 | Test MAE  | Test RMSE | Test R²| CV R² | CV R² | CV MAE 평균 |
|---|---|---|---|---|---|---|
| Linear Regression | 0.0375 | 0.0541 | `0.7425` | 0.7789 | 0.0357 | 0.0352|
| Random Forest Regressor | 0.0528 | 0.0628 | 0.6533 |0.6451 |0.0641 | 0.0496 |

## 12. 분석 결과

두 회귀 모델의 성능을 비교한 결과, 본 데이터에서는 `Linear Regression`이 `Random Forest Regressor`보다 높은 `R²`를 기록하였다.
