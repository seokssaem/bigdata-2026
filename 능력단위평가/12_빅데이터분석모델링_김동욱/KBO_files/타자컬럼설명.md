# 타자

## 컬럼 설명

| 컬럼명 | 설명 | 상세설명 |
|---|---|---|
| 선수 | 선수 이름 | |
| 팀 | 소속 팀 | 시즌 소속 팀 이름 |
| 타율 | 안타/타수 | 타수가 얼마나 안타로 이어졌는지를 나타내는 비율 |
| 경기 | 참여한 경기 수 | 실제로 경기에 참여한 횟수 |
| 타석 | 타석에 올라간 수 | 경기 중 1번의 공격 기회를 마친 횟수 |
| 타수 | 타석의 결과 | 1타석의 결과 중 타자의 능력을 평가할 수 있는 경우만 기록. 볼넷, 데드볼, 희생번트, 희생플라이는 기록되지 않음 |
| 득점 | 홈플레이트를 밟아서 올린 득점 | 직접 홈플레이트로 들어온 경우에만 기록 |
| 안타 | 타자가 출루한 횟수 | 타자가 수비 실책 없이 출루한 횟수. 볼넷, 데드볼, 실책, 야수선택은 기록되지 않음 |
| 2루타 | 안타 중 타자가 2루까지 진루한 횟수 | 타자가 친 타구로 타자가 2루까지 진루한 횟수 |
| 3루타 | 안타 중 타자가 3루까지 진루한 횟수 | 타자가 친 타구로 타자가 3루까지 진루한 횟수 |
| 홈런 | 안타 중 타자가 홈까지 들어온 횟수 | 타자가 친 타구로 홈까지 들어온 횟수. 홈런, 그라운드 홈런 기록 |
| 루타 | 안타 중 타자가 진루한 베이스 수 | 1루타 = 1, 2루타 = 2, 3루타 = 3, 홈런 = 4 |
| 타점 | 타자가 올린 득점 기여 수 | 실책·병살 등으로 인한 득점은 타점으로 인정되지 않을 수 있음 |
| 도루 | 주자가 다음 베이스를 훔친 횟수 | 투수의 투구 중 타자가 아닌 주자가 다음 베이스로 진루하고 성공한 횟수 |
| 도루 실패 | 도루 시도가 실패로 기록된 횟수 | 주자가 도루를 시도했으나 도루 성공으로 인정되지 않은 횟수
| 볼넷 | 볼 4개를 받아 출루한 횟수 | 타자가 4개의 볼을 받아 1루에 진출한 횟수. 고의사구도 포함 |
| 사구 | 데드볼 | 투수가 던진 공에 타자가 맞아 1루에 진출한 횟수 |
| 삼진 | 삼진으로 아웃된 횟수 | 타자가 3개의 스트라이크를 받아 아웃된 횟수 |
| 병살 | 한 플레이에서 2개의 아웃 발생 수 | 한 플레이에서 2개의 아웃 발생, 타자로 인한 것이 아니면 기록 안됨 |
| 장타율 | 타수 대비 얻은 루타 비율 | 1루타=1, 2루타=2, 3루타=3, 홈런=4로 계산 |
| 출루율 | 타석 대비 출루 비율 | 타자가 안타, 볼넷, 몸에 맞는 공 등으로 출루한 비율 |
| OPS | 장타율 + 출루율 | 장타율과 출루율의 합
| 실책 | 수비 실수 횟수 | 수비수가 정상적으로 처리할 수 있는 타구나 플레이를 실패하여 상대에게 진루 또는 출루를 허용한 횟수 |
| 희생플라이 | 희생플라이 기록 횟수 | 타자가 뜬공을 쳐서 아웃되었지만, 그 사이 주자가 홈에 들어와 득점한 횟수 |
| 희생번트 | 희생번트 기록 횟수 | 타자가 아웃되는 대신 주자의 진루를 돕기 위해 번트를 댄 횟수 |
| 장타 | 장타를 친 횟수 | 2루타, 3루타, 홈런의 합계. 1루타는 포함하지 않음 |
| 땅볼 | 땅볼을 친 횟수 | 타자가 친 타구가 지면을 따라 굴러간 횟수 |
| 뜬공 | 뜬공을 친 횟수 | 타자가 친 타구가 공중으로 떠서 날아간 횟수 |
| 땅볼/뜬공 | 땅볼과 뜬공의 비율 | 땅볼 개수를 뜬공 개수로 나눈 값. 타구 성향을 나타내는 지표 |
| 결승타 | 승패를 결정한 타격 기록 횟수 | 경기에서 최종적으로 승리를 결정한 득점을 만든 타격 기록 |
| 투구수/타석 | 타석당 평균 투구 수 | 타자가 한 타석을 마칠 때까지 상대 투수가 던진 공의 평균 개수 |
| 추정득점 | 타격 성과를 바탕으로 계산한 예상 득점 기여도 | 안타, 출루, 장타 등 타격 기록을 활용해 선수가 만들어낸 예상 득점 수 |
| 고의사구 | 고의로 허용한 볼넷 횟수 | 투수가 타자와 승부하지 않고 일부러 볼넷을 내줘 1루로 보낸 횟수 |
| 멀티히트 | 한 경기에서 2개 이상 안타를 기록한 경기 수 | 한 경기에서 2개 이상의 안타를 기록한 횟수 |
| 득점권타율 | 득점권 상황에서의 타율 | 주자가 2루 또는 3루에 있는 득점 기회 상황에서 기록한 안타 비율 |
| 대타타율 | 대타로 출전했을 때의 타율 | 경기 중 교체 선수로 타석에 들어온 상황에서 기록한 안타 비율 |
| 볼넷/삼진 | 볼넷 대비 삼진 비율 | 볼넷 개수를 삼진 개수와 비교한 값으로, 선구안과 타격 성향을 나타내는 지표 |
| 순수장타율 | 장타 생산 능력을 나타내는 지표 | 장타율에서 타율을 뺀 값으로, 단타를 제외한 추가 장타 생산 능력을 나타냄 |
| GPA | 종합 타격 생산성을 나타내는 지표 | 타율, 출루율, 장타율 등을 활용해 타자의 공격력을 평가하는 종합 지표 |
| wRC+ | 평균 대비 조정된 득점 생산력 | 타자가 평균 대비 얼마나 많은 득점을 만들어냈는지를 나타내는 지표. 100이 평균 |
| wOBA | 가중치를 적용한 출루율 | 안타, 볼넷, 장타 등 각각의 공격 결과에 다른 가치를 적용해 타자의 실제 득점 기여도를 평가하는 지표 |
| WAR | 대체 선수 대비 승리 기여도 | 해당 선수가 같은 포지션의 대체 선수보다 팀 승리에 얼마나 더 기여했는지를 나타내는 지표 |
| BABIP | 인플레이 타구의 안타 비율 | 홈런과 삼진을 제외하고, 수비가 개입되는 타구가 안타가 된 비율 |
| 볼넷비율 | 타석 대비 볼넷 비율 | 전체 타석 중 볼넷을 기록한 비율. 타자의 선구안을 평가하는 지표 |
| 삼진비율 | 타석 대비 삼진 비율 | 전체 타석 중 삼진으로 아웃된 비율. 타자의 컨택 능력과 헛스윙 성향을 평가하는 지표 |
| RC | 타자가 만들어낸 예상 득점 | 안타, 출루, 장타, 주루 등의 공격 기록을 바탕으로 타자가 팀 득점에 기여한 정도를 추정한 지표 |
| SecA | 추가 공격 생산력 | 타율 외에 볼넷, 장타, 도루 등을 포함해 타자가 추가로 만들어낸 공격력을 평가하는 지표 |
