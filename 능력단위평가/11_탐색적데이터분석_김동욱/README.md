# 탐색적 데이터 분석 (EDA)

전처리가 완료된 고객 데이터셋(`prj_data_eda.csv`)을 대상으로 데이터의 특성과 변수 간 관계를 탐색한 분석입니다.

## 데이터 개요

- 데이터: `prj_data_eda.csv` (500행 × 21열)
- 결측치·이상치 처리, 범주형 인코딩(원-핫/레이블), 수치형 스케일링(StandardScaler)까지 완료된 상태
- 수치형 변수: 나이, 멤버십등급, 월평균구매금액, 구매횟수, 리뷰점수, 이탈여부, 평균구매단가
- 범주형 변수: 고객ID, 성별(남/여), 거주지역(경기/기타/대구/부산/서울), 가입경로(광고/앱/웹/지인추천), 쿠폰사용여부(N/Y)

> 나이, 월평균구매금액, 구매횟수, 리뷰점수, 평균구매단가는 StandardScaler로 표준화되어 있어 절대적인 단위(원, 세, 회 등)가 아닌 평균 0, 표준편차 1 기준의 상대값입니다.

## 1. 데이터 기초 특성 파악

`shape`, `dtypes`, `describe()`로 전체 구조를 확인하고, dtype 기준으로 수치형/범주형 변수를 구분했습니다. 범주형 변수 중 성별(남/여)의 빈도를 `value_counts()`로 확인했습니다(남 230명, 여 270명).

## 2. 단변량/분포 시각화

- **히스토그램**: 멤버십등급 분포 확인
- **countplot**: 성별(성별_여) 분포 확인

**설명**
- 멤버십등급 분포는 브론즈 등급에 고객이 가장 많이 몰려 있고(192명), 등급이 높아질수록(실버 142명 → 골드 111명 → VIP 55명) 고객 수가 점차 감소하는 형태를 보이며, 왜도는 약 0.51로 양의 값을 나타내어 낮은 등급 쪽으로 치우친 분포임을 수치로도 확인할 수 있다.
- 특히 골드에서 VIP로 갈 때 고객 수가 약 50% 감소하여, 다른 구간(20%대 감소)에 비해 가장 큰 폭으로 줄어드는 특이 구간으로 나타난다.

## 3. 상관관계 및 이변량 분석

수치형 변수 간 상관계수 행렬을 `corr()`로 계산하고 heatmap으로 시각화했습니다. 상관관계가 가장 높은 변수 쌍(멤버십등급-구매횟수, 상관계수 0.88)을 scatterplot과 boxplot으로 시각화했습니다.

**설명**
- 멤버십등급과 구매횟수는 상관계수 0.88로 매우 강한 양의 상관관계를 보이며, scatterplot과 boxplot 모두에서 등급이 높아질수록 구매횟수의 중앙값과 분포 전체가 꾸준히 상승하는 패턴이 뚜렷하게 나타난다.
- 특히 브론즈와 VIP 등급 간에는 구매횟수 분포가 거의 겹치지 않을 정도로 뚜렷한 차이를 보인다.
- 단, 이는 상관관계일 뿐이며 등급이 높아서 구매를 많이 하게 된 것인지 구매를 많이 해서 등급이 상승한 것인지는 이 분석만으로 인과관계를 단정할 수 없다.

## 4. 그룹별 비교 분석 및 인사이트 도출

성별(남/여)을 기준으로 `groupby()`를 이용해 주요 지표(나이, 멤버십등급, 월평균구매금액, 구매횟수, 리뷰점수, 이탈여부, 평균구매단가)의 평균을 비교하고 막대그래프로 시각화했습니다.

### 인사이트

**성별은 구매 성향을 구분하는 요인이 아니다.** 나이, 월평균구매금액, 구매횟수, 리뷰점수, 평균구매단가 등 스케일링된 5개 지표는 남녀 간 차이가 -0.03~0.03 수준으로 매우 작다. 멤버십등급 역시 남(1.05)과 여(1.07)로 거의 동일하다.
