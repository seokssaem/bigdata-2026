.env 파일로부터 API_KEY 를 호출받아 공공데이터 포털의 대구광역시_수질정보 조회 서비스_GW API를 불러왔습니다.

대구광역시_수질정보 조회 서비스_GW 자료에는 년도별 월별 수질검사 항목(PH, 탁도, 잔류염소)이 포함되어 있었습니다.

행정구역별 정수장을 연결해서 수질검사 내용을 알 수 있으면 일반 사용자가 찾아보기에 유용할 것 같아서 정수장별 급수구역 자료를 작성했습니다. (= area.csv)

대구광역시_수질정보 조회 서비스_GW 자료를 데이터프레임으로 만들었습니다. (= df)

df 에서 월 별로 나눠둔 컬럼을 하나의 컬럼으로 합쳤습니다. (= df_1)

df_1 에서 행으로 나눠진 수질검사 항목(PH, 탁도, 잔류염소)을 각각 컬럼으로 변경하였습니다. (= df_2)

df_2 에서 데이터프레임을 정리하고 컬럼 순서를 재배치하였습니다. (= df_water)

df_water 에서 수질검사 항목(PH, 탁도, 잔류염소)을 실수형태로 형변환하였습니다.

완성된 df_water과 area.csv를 기반으로 pgadmin 4에 테이블을 생성하였습니다. (= waterdb, areadb)

그 후 output 폴더에 완성된 파일들을 csv 형식으로 저장하였습니다.

이제 필요하다면 pgadmin에 저장된 두 테이블을 활용하여 행정구역별 수질검사 항목을 조회할 수 있습니다.
