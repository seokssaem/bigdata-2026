# 화재 발생 특성에 따른 인명피해 예측 분석

빅데이터 팀플 3 | 데이터 분석 모델링 과제

## 프로젝트 개요

전국 화재 사건 데이터(fire.csv)를 활용하여, 발화요인·화재 발생 장소·발생 시점(월·시간·요일)·지역(시도)에 따라
인명피해 발생 여부를 예측하는 분류 모델을 개발한다.

- 종속변수(Y): `인명피해_발생여부` (0/1)
- 독립변수(X): `시도`, `발화요인소분류`, `장소대분류`, `발생_월`, `발생_시간`, `발생_요일`
- 모델: `RandomForestClassifier` (class_weight='balanced')
- 데이터 분할: Stratified Train/Test (75:25)
- 평가지표: ROC-AUC, Recall, Precision, F1-score, 변수 중요도(그룹별 재계산)

## 실행 방법

python train.py 실행

streamlit run fire_streamlit.py 실행


- `fire.csv`와 `fire.py`를 같은 폴더에 두고 실행
- 실행 후 `casualty_model.joblib`(학습된 파이프라인), `metrics.json`(평가 결과)가 생성됨
- `metrics.json`와 `fire_streamlit.py`를 같은 폴더에 두고 실행

## 파일 구성

| 파일 | 설명 |
|---|---|
| `fire.py` | 데이터 전처리 → 모델 학습 → 평가까지 하나의 파이프라인으로 구조화한 코드 |
| `fire.csv` | 분석 대상 데이터 (전국 화재 사건별 기록) |

## 주요 결과 요약

- ROC-AUC: 0.770
- Recall: 0.85 / Precision: 0.08 (Threshold=0.3 기준)
- 변수 중요도(그룹별): 발화요인소분류 > 장소대분류 > 시도 ≈ 발생_시간 > 발생_월 > 발생_요일
- 결론: 화재의 인명피해 여부는 발생 시점보다 **발화요인(원인)과 발생 장소**에 더 크게 좌우된다
