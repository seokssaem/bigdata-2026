**오전**

## 1. 독립표본 t-검정 (Independent t-test)
- 목적: 두 독립된 그룹의 평균 차이 검정
    - 파이썬 인자 (`ttest_ind`): 표본 데이터, 대립가설(`alternative`), 등분산 여부(`equal_var`)
- 비모수 검정: 정규성 위배 시(샤피로 검정 실패) 맨-휘트니 U 검정 수행

## 2. 분산분석 (ANOVA)
- 목적: 3개 이상 집단의 평균 차이 검정 (2개 집단은 t-검정 사용)
- 종류: 
    - 일원분산분석: 독립변수 1개
    - 이원분산분석: 독립변수 2개
- 분석 순서: 정규성 검정 -> 등분산성 검정 -> 일원분산분석 수행

## 3. 데이터 입력 용어 비교
    - 통계학: 독립변수, 요인(Factor)
    - 머신러닝: 피처(Feature), 변수, 입력 컬럼

**오후**

## 4. JWT (JSON Web Token)
- 목적: 클라이언트와 서버 간 안전한 정보 전송을 위한 무상태(Stateless) 토큰
- 구조: `Header.Payload.Signature`
    - Header: 토큰 타입, 암호화 알고리즘
    - Payload: 사용자 정보 및 데이터 (민감 정보 포함 금지)
    - Signature: 토큰 위변조 방지용 서버 서명
