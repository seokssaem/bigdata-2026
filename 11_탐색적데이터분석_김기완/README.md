# 고객 데이터 탐색적 데이터 분석(EDA) 결과 요약

## 1. 데이터 기초 특성 파악
- 데이터 크기: 500행 × 11열
- 수치형 변수: 나이, 월평균구매금액, 구매횟수, 리뷰점수
- 범주형 변수: 성별, 거주지역, 가입경로, 멤버십등급, 쿠폰사용여부
- 거주지역 분포: 서울 155명, 경기 123명, 대구 89명, 부산 80명, 기타 53명

## 2. 단변량 / 분포 시각화
- 월평균구매금액 히스토그램 확인 결과 왜도 0.91로 오른쪽으로 치우친 분포
- 대부분 5~15만원대에 몰려 있고 20만원 넘는 고객은 소수
- 거주지역별로는 서울, 경기에 고객이 다소 몰려 있고 나머지 지역은 비슷한 수준

## 3. 상관관계 및 이변량 분석
- 수치형 변수 간 상관계수 히트맵 확인
- 최고 상관 변수 쌍: 월평균구매금액 - 구매횟수 (r=0.77)
- 상관관계일 뿐이며, 구매를 많이 해서 금액이 커진 것인지 원래 소비 성향이 큰 고객이 구매도 많이 하는 것인지는 이 데이터만으로 인과관계를 판단할 수 없음
- 거주지역별 월평균구매금액 분포에도 차이가 있음을 boxplot으로 확인

## 4. 그룹별 비교 분석 및 인사이트 도출
- 멤버십등급별 평균: VIP 172,518원 / 골드 118,243원 / 실버 79,339원 / 브론즈 47,742원
- 등급 × 이탈여부별 평균 구매금액도 함께 비교

### 인사이트
1. 등급이 올라갈수록 구매금액과 구매횟수가 함께 증가한다 → 등급 혜택이 실제 구매 활성화에 기여하고 있을 가능성이 있어, 상위 등급 승급 유도 프로모션이 효과적일 수 있다.
2. 같은 등급 내에서도 이탈여부에 따라 평균 구매금액 차이가 나타난다 → 등급만으로는 이탈을 설명하기 부족하며, 구매횟수·리뷰점수를 함께 활용한 이탈 예측이 필요해 보인다.
