# 급여·비급여 의약품 연령금기 비교 분석 플랫폼

식품의약품안전처 DUR(OpenAPI) 데이터를 기반으로 급여 의약품과 비급여 의약품의
연령금기 현황을 비교 분석하여 HTML/CSS 대시보드 형태로 구현한 프로젝트입니다.

---

## 프로젝트 목적

연령금기 의약품 정보를 시각적으로 제공하여 급여·비급여 의약품의 분포를 비교하고,
의료진, 약사, 일반 국민이 의약품 안전사용 현황을 쉽게 확인할 수 있도록 제작하였습니다.

---

## 사용 데이터 출처

https://www.data.go.kr/tcs/dss/selectFileDataDetailView.do?publicDataPk=15089531

데이터 형식: OpenAPI
주요 데이터 : 의약품명, 성분명, 업체명, 급여구분, 특정연령, 공고일자

---

## 구현 기능 요약

- 급여/비급여 의약품 현황 조회
- 의약품명 검색 기능
- 핵심 통계 카드 제공
- 제약회사별 현황 
- 연령대별 현황 제공
- 분석 결과 요약
