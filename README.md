# 영화 박스오피스 분석 플랫폼

## 사용 데이터 출처
- 영화진흥위원회(kobis.or.kr) API → 일별 박스오피스

## 구현 기능
- 핵심 통계 카드
    - flex 기능 사용 → 4개의 카드 1줄에 표시
    - 미디어쿼리 기능 사용
        - max-width가 435px → 4개의 카드를 1줄에 한 개씩 표시
        - max-width가 1024px → 4개의 카드를 1줄에 두 개씩 표시

- 순위표
    - grid 기능 사용 → 행 하나씩 grid를 적용해서 11행 5열의 표 형식으로 구현
    - 미디어쿼리 기능 사용
        - 화면 크기가 작아짐에 따라 폰트 크기를 줄임

- 등급 기준 카드
    - flex 기능 사용 → 4개의 카드 1줄에 표시
    - 미디어쿼리 기능 사용
        - max-width가 768px → 4개의 카드를 1줄에 두 개씩 표시
        
- 푸터
    - 미디어쿼리 기능 사용
        - 화면 크기가 작아짐에 따라 폰트 크기를 줄임
