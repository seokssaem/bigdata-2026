# 📊 대구광역시 수성구 교육 인프라 현황 분석

> **공공데이터(OpenAPI)를 활용한 교육환경 빅데이터 시각화 프로젝트**

---

## 📖 프로젝트 소개

본 프로젝트는 **공공데이터포털(data.go.kr)**의 교육 관련 데이터를 활용하여 **대구광역시 수성구의 교육 인프라 현황**을 분석하고 시각화한 웹 기반 대시보드입니다.

수성구의 고등학교 현황과 주요 교과(국어·영어·수학·과학) 학원 분포를 비교하여 교육 인프라의 특징을 직관적으로 확인할 수 있도록 구현하였습니다.

---

## 🎯 프로젝트 목표

* 공공데이터(OpenAPI)를 활용한 데이터 수집
* HTML/CSS를 이용한 웹 UI 구현
* 교육 데이터를 차트 및 표로 시각화
* 학교와 학원의 분포를 비교하여 교육 인프라 분석

## 📌 주요 기능

### 🟢 1. 핵심 통계(KPI)

수성구 교육환경을 대표하는 주요 데이터를 카드 형태로 제공합니다.

| 항목            |      내용 |
| ------------- | ------: |
| 🏫 고등학교 수     |    23개교 |
| 👨‍🎓 총 재학생 수 | 16,840명 |
| 📚 등록 학원 수    | 1,226개소 |
| 📈 교육 인프라 밀집도 |   5.41% |

---

### 📊 2. 과목별 등록 학원 수 현황

막대그래프를 활용하여 주요 교과 학원의 분포를 시각화하였습니다.

| 과목 | 학원 수 |
| -- | ---: |
| 국어 |  210 |
| 영어 |  380 |
| 수학 |  486 |
| 과학 |  150 |

**분석 결과**

* 수학 학원이 가장 많은 비중을 차지함
* 영어 학원이 두 번째로 많이 분포
* 국어와 과학 학원은 상대적으로 적은 비중을 보임

---

### 🏫 3. 학교당 학원 매칭 비율

학교 1개교당 주요 교과 학원 수를 비교하여 교육 인프라 접근성을 분석하였습니다.

| 지역      | 학교 수 | 주요 교과 학원 수 | 학교당 학원 수 |
| ------- | ---: | ---------: | -------: |
| **수성구** |   23 |      1,226 | **53.3** |
| 달서구     |   24 |        924 |     38.5 |
| 북구      |   18 |        612 |     34.0 |
| 중구      |    9 |        241 |     26.8 |

**분석 결과**

* 수성구는 비교 지역 중 학교당 학원 수가 가장 높게 나타났다.
* 범어동·만촌동을 중심으로 학원가가 밀집되어 있어 학생들의 교육 접근성이 우수한 것으로 분석된다.
* 타 지역 대비 사교육 인프라가 집중된 지역적 특성을 확인할 수 있다.

---
