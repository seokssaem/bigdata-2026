# 기술은행 수요기술 데이터베이스 구축

## 프로젝트 소개

본 프로젝트는 기술은행 수요기술 데이터를 PostgreSQL 데이터베이스에 저장하기 위한 파이프라인을 구축한 프로젝트이다.

CSV 형태로 저장된 기술은행 데이터를 배치 단위로 적재하고, 중복 데이터를 방지하기 위한 제약 조건을 적용하였다. 또한 데이터 적재 후 검증 절차를 수행하여 데이터의 무결성을 확인하도록 구현하였다.

---

## 프로젝트 구조

```text
.
├── database.py      # 데이터베이스 연결 및 테이블 생성
├── models.py        # SQLAlchemy ORM 모델 정의
├── loader.py        # CSV 데이터를 PostgreSQL에 적재
├── verify.py        # 데이터 적재 결과 검증
├── pipeline.py      # 전체 파이프라인 실행
└── data/
    └── NTB_db.csv
```

---

## 파일별 기능

### database.py

PostgreSQL 데이터베이스와 연결을 생성하는 모듈이다.

주요 기능은 다음과 같다.

- SQLAlchemy Engine 생성
- Session 객체 생성
- 테이블 초기화
- 데이터베이스 세션 반환

---

### models.py

기술은행 데이터를 저장하기 위한 ORM 모델을 정의하였다.

주요 특징은 다음과 같다.

- `tech` 테이블 정의
- 데이터 타입 지정
- Primary Key 설정
- 복합 UNIQUE 제약조건 적용

UNIQUE 제약조건 : 중복 데이터 방지를 위해 다음 세 컬럼을 업무 키(Business Key)로 설정하였다.

- 수요기술명
- 진행상태
- 기술도입지원기관

---

### loader.py

CSV 파일을 읽어 PostgreSQL에 적재하는 모듈이다.

주요 기능은 다음과 같다.

- CSV 배치 단위 읽기
- 데이터 전처리
- 날짜 형식 변환
- 필수 컬럼 결측치 제거
- PostgreSQL INSERT
- 중복 데이터 자동 제거
- 적재 결과 집계

PostgreSQL의 `ON CONFLICT DO NOTHING` 기능을 사용하여 중복 데이터를 자동으로 제외하도록 구현하였다.

---

### verify.py

적재 완료 후 데이터의 무결성을 검증하는 모듈이다.

다음 항목을 검증한다.

- 전체 적재 건수
- NULL 데이터 존재 여부
- 정보충실도 음수 여부
- 기술센터지역 이상값 여부
- 업무 키 중복 여부

모든 검증을 통과하면 `PASS`, 하나라도 실패하면 `FAIL`을 출력한다.

---

### pipeline.py

전체 저장 과정을 순차적으로 실행하는 메인 모듈이다.

실행 순서는 다음과 같다.

1. 테이블 생성
2. CSV 데이터 적재
3. 데이터 검증

각 기능을 하나의 파이프라인으로 통합하여 실행할 수 있도록 구현하였다.

---

## 처리 과정

```text
NTB_db.csv
      │
      ▼
CSV 읽기
      │
      ▼
데이터 전처리
      │
      ▼
PostgreSQL 적재
      │
      ▼
중복 제거
      │
      ▼
데이터 검증
      │
      ▼
완료
```

---

## 데이터 검증 항목

| 검증 항목   | 내용               |
| ------- | ---------------- |
| 전체 건수   | 데이터 적재 여부 확인     |
| NULL 검사 | 필수 컬럼 NULL 여부 확인 |
| 정보충실도   | 음수 데이터 존재 여부 확인  |
| 기술센터지역  | 허용된 지역값 여부 확인    |
| 중복 검사   | 업무 키 중복 여부 확인    |

---

## 실행 방법
```bash
python pipeline.py
```

실행 시 다음 순서대로 작업을 수행한다.

1. 데이터베이스 초기화
2. CSV 데이터 적재
3. 데이터 무결성 검증

---

## 프로젝트 특징

* SQLAlchemy ORM을 활용한 데이터베이스 설계
* PostgreSQL 기반 데이터 저장
* 배치 단위 적재를 통한 대용량 데이터 처리
* 복합 UNIQUE 제약조건을 활용한 중복 방지
* 데이터 적재 후 자동 검증 기능 구현
* ETL 파이프라인 구조 적용
